# Cambios integrados de BAZUKO

34 capturas reales, dos por cada uno de los 17 temas. Tomadas el 1 de noviembre de 2026 en Chromium sobre el código `fe7c7f725c8db46440758c21d6730777d78ded84`. Las imágenes se convirtieron a WebP para reducir su peso.

Las vistas de celular corresponden a tamaños de navegador simulados; no acreditan una prueba en teléfono físico. Las escenas de sala se identifican en cada sección. Las escenas de arresto, recuperación y recorrido se prepararon en una sesión local aislada. Las capturas no son mediciones de FPS ni validación de producción.
